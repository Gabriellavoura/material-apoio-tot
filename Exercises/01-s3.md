# Exercício 01 · Buckets S3 com Floci

**Objetivo:** subir o Floci, criar dois buckets S3 e enviar arquivos para eles usando a AWS CLI.

**Antes de começar:** leia o [guia 03: AWS local com Floci](../docs/03-aws-local-floci.md) e confira se a AWS CLI e o perfil `floci` estão configurados ([guia 01](../docs/01-ambiente.md#6-aws-cli-v2)).

## Passo a passo

1. Crie uma pasta `exercicio-01` com o `compose.yaml` do [guia 03](../docs/03-aws-local-floci.md#subindo-o-floci) e suba o Floci:

   ```shell
   docker compose up -d
   ```

2. Confira se o Floci está no ar:

   ```shell
   curl http://localhost:4566/_floci/health
   ```

   > A resposta deve listar os serviços com `"running"`, incluindo `"s3"`.

3. Crie o primeiro bucket (troque `<nome-1>` por um nome seu, só com letras minúsculas, números e hífen):

   ```shell
   aws --profile floci s3 mb s3://<nome-1>
   ```

4. Crie o segundo bucket:

   ```shell
   aws --profile floci s3 mb s3://<nome-2>
   ```

5. Liste os buckets:

   ```shell
   aws --profile floci s3 ls
   ```

6. Envie um arquivo qualquer para o primeiro bucket e liste o conteúdo:

   ```shell
   echo "olá, ToT" > teste.txt
   aws --profile floci s3 cp teste.txt s3://<nome-1>/
   aws --profile floci s3 ls s3://<nome-1>
   ```

7. Abra o floci-ui em `http://localhost:4500` e encontre os buckets e o arquivo pela tela.

## Desafio extra

- Copie o arquivo do primeiro para o segundo bucket usando só a AWS CLI.
- Escreva um script `criar-buckets.sh` que cria os dois buckets e coloque-o em `ready.d`, para que eles sejam criados sozinhos quando o Floci subir. Veja [criando recursos automaticamente](../docs/03-aws-local-floci.md#criando-recursos-automaticamente).

## Limpeza

```shell
docker compose down
```

## Entrega

Um repositório no GitHub com o `compose.yaml`, o script do desafio extra e um README explicando como rodar.
