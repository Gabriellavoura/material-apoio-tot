# 06 · Inteligência Artificial

A IA aparece no ToT de dois jeitos:

1. **Como parte do vddb:** modelos de linguagem (LLMs) rodando localmente para tratar textos.
2. **Como ajuda no dia a dia:** assistentes que sugerem código, explicam erros e revisam o que você escreveu.

## IA local: Ollama e llama.cpp

Rodar o modelo **no seu computador** é gratuito, funciona sem internet e **nenhum dado sai da sua máquina**. Por isso é o caminho indicado para dados de pesquisa.

| Ferramenta | Quando usar | Documentação |
|------------|-------------|--------------|
| **Ollama** | Para começar. Instala e roda modelos com um comando. | [docs.ollama.com](https://docs.ollama.com/) · [modelos](https://ollama.com/search) |
| **llama.cpp** | Quando precisar de mais controle e desempenho. | [github.com/ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) |

Primeiro teste com o Ollama:

```shell
ollama run llama3.2
```

O Ollama também tem uma API em `http://localhost:11434`, que você pode chamar pelo Python. Veja a [referência da API](https://docs.ollama.com/api).

> Modelos grandes precisam de bastante memória RAM (ou de placa de vídeo). Comece com modelos pequenos, de 1B a 4B parâmetros.

## Assistentes de código

| Assistente | Para estudantes | Documentação |
|------------|-----------------|--------------|
| **GitHub Copilot** | :white_check_mark: **Gratuito** pelo plano *Copilot Student*, com verificação de estudante no [GitHub Education](https://github.com/education/students). Tem sugestões de código ilimitadas e um uso limitado de chat e agente, com o modelo escolhido automaticamente. | [docs.github.com/copilot](https://docs.github.com/pt/copilot) · [planos](https://docs.github.com/en/copilot/get-started/plans) |
| **Claude** (Anthropic) | O plano gratuito do [claude.ai](https://claude.ai/) serve para tirar dúvidas e revisar código. O acesso estudantil completo é pelo [Claude for Education](https://www.anthropic.com/education) e depende de a universidade ter convênio. O **Claude Code** (no terminal) exige plano pago. | [docs.claude.com](https://docs.claude.com/) · [Claude Code](https://code.claude.com/docs) |
| **Codex** (OpenAI) | Vem junto com os planos do ChatGPT. Não há plano específico para estudantes. | [developers.openai.com/codex](https://developers.openai.com/codex) |

**Nossa recomendação:**

1. **Comece pelo GitHub Copilot Student**: é gratuito e já funciona no VSCode.
2. Use o **plano gratuito do Claude** ou do ChatGPT para perguntas e explicações.
3. **Claude Code e Codex** são opcionais, caso o laboratório ou a universidade ofereça acesso.
4. Para **dados da pesquisa**, use **IA local** (Ollama).

> Planos e preços mudam com frequência. Confira sempre a página oficial de cada ferramenta. Informações revisadas em outubro de 2026.

## Regras de uso

1. **Entenda antes de usar.** Só faça commit de código que você consegue explicar linha por linha.
2. **Tente sozinho primeiro.** Nos exercícios da trilha, resolva por conta própria e use a IA para **revisar** e **tirar dúvidas**, não para fazer por você. O objetivo é aprender.
3. **Nunca envie segredos.** Senhas, tokens e arquivos `.env` não vão para nenhuma IA na nuvem.
4. **Cuidado com dados de pesquisa.** Dados não publicados, dados pessoais e dados de parceiros só podem ir para IA local, a não ser que a orientação autorize outra coisa.
5. **Confira os fatos.** A IA pode inventar funções, bibliotecas e referências que não existem. Confirme na documentação oficial.
6. **Declare o uso.** Em artigos, relatórios e na dissertação, siga a regra do seu programa e da revista sobre declarar o uso de IA.
