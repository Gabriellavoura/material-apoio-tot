# 00 · Primeira semana

Um checklist simples para os seus primeiros dias no ToT. Marque cada item quando terminar.

## Contas e acessos

- [ ] Criar (ou atualizar) sua conta no [GitHub](https://github.com/signup). Use um nome de usuário profissional.
- [ ] Ativar a [verificação em duas etapas no GitHub](https://docs.github.com/pt/authentication/securing-your-account-with-two-factor-authentication-2fa).
- [ ] Pedir o seu benefício de estudante no [GitHub Education](https://github.com/education). Ele libera o GitHub Copilot gratuito (veja o [guia de IA](06-ia.md)).
- [ ] Enviar seu usuário do GitHub para a coordenação, para ser adicionado à organização do projeto.
- [ ] Entrar nos canais de comunicação da equipe.

## Computador pronto

- [ ] Seguir o [guia de ambiente](01-ambiente.md) até o fim.
- [ ] Rodar o [projeto base](../templates/projeto-base/) e abrir `http://localhost:8000/docs` no navegador.

## Conhecendo o projeto

- [ ] Ler o README do vddb e os documentos de arquitetura que a equipe indicar.
- [ ] Conversar com a pessoa que vai te acompanhar (mentor ou orientador) sobre a sua primeira tarefa.
- [ ] Começar a [trilha de exercícios](../README.md#zap-trilha-de-exercícios).

## Combinados da equipe

- **Pergunte cedo.** Se ficar travado por mais de 1 hora no mesmo problema, peça ajuda. Conte o que já tentou.
- **Anote suas dificuldades.** Elas ajudam a melhorar este material para quem chegar depois.
- **Nada de segredos no Git.** Senhas, tokens e arquivos `.env` nunca vão para o repositório.
- **Tudo passa por Pull Request.** Ninguém envia código direto para a branch `main`.
- **Use IA com responsabilidade.** Leia as [regras de uso](06-ia.md#regras-de-uso).
